### About this repo

#### What you'll find here
I would say there are 3 categories of player knowledge relevant for Bellwright:
1. Encyclopedia knowledge (raw stats, costs, effect, item lists, etc)
2. Detailed explanations about certain systems and mechanics
3. Guides from A to Z, "How to start", etc

I want to focus on 2. only. I feel in Bellwright there is a huge need for that and it is something that is more interesting for me. Typing out item and stat lists would bore me to death, except if there was sth. interesting contained in those (some derivable general rule or distribution that could be analyzed)

#### How I work
I try to take a scientific approach for exploring game mechanics of Bellwright. For this I differentiate between actual tests + data and interpretations. It's an interesting and fun angle to me.

So basically you will be linked to the interpretations. These are the conclusions derived from actual hard tested data that is linked to every interpretation page. Others are invited use my data or testing concepts and do it better then me. So especially correcting feedback would be welcomed

#### Why not directly adding this data to a wiki?
I invite every Bellwright wiki author to just copy my findings/content without any reference to me.

However I don't think a wiki would allow for my data driven and documenting approach that is strongly aimed at researching game mechanics. Especially the separation between data/tests from interpretations is very central to me.

 Also I'd like to keep the overhead of publishing my data and findings as minimal as possible.

### Is this still up to date?
100% I won't commit continuing this forever. Even not for the whole EA process of the game. I continue doing this as long as I have fun doing it.

I won't be publishing a "This is now deprecated" message: Instead please check the [changelog](./changelog.md). If the last update is older than 3 months, this repo has gone stale. If it's been longer than a year: It's probably been abandoned and I would be highly cautious about every data and interpretation.
