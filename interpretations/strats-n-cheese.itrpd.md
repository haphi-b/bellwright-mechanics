# Strats n' Cheese
In Bellwright there are of course also cheesy methods to do something. I want to point them out separately because these might not be the intended ways for the game to be played. Using them enables normally impossible things or simply helps you significantly. 

**Disclaimer for own good:**  
However keep in mind these things can be done (because no game can shield you from all cheesy ways) but might not be intended to. Just because you can doesn't mean you should. Using them will lead to more grindy and simplified gameplay. Thus it might potentially ruin fun without you noticing it being the cause.
